# 3019_Fitri-Ramadhani_Tugas-Slicing-Website

project ini saya namakan Kayanya KFC dikarenakan saya terinspirasi dari landing page website resmi KFC
project ini (jelas) menggunakan HTML, CSS, dan JS

fitur-fiturnya ada:
- Dropdown menu untuk menu "Layanan" bisa dibuka/tutup dengan klik, otomatis tertutup saat klik di luar area dropdown
- Hero untuk banner utama dengan judul dan tombol CTA
- Feature grid untuk 4 kartu informasi (Promo, Menu, Outlet, Kontak)
- Menu highlight untuk daftar menu makanan dengan gambar, nama, dan harga
- CTA banner untuk ajakan bergabung sebagai member
- Floating button untuk tombol "Pesan Sekarang" yang otomatis muncul saat halaman di scroll ke bawah, dan otomatis scroll ke section menu 
  saat diklik
- Fully responsive untuk menyesuaikan tampilan di desktop, tablet, dan mobile
